# Nosh Robotics Recipe Assistant

A conversational chatbot that searches, analyzes, matches, and adapts recipes from the [Eight Portions Recipe Box dataset](https://eightportions.com/datasets/Recipes/). All factual answers are grounded in the dataset — the LLM never guesses counts, rankings, or recipe content.

## Quick Start

### 1. Prerequisites
- Python 3.10+
- A [Google AI Studio](https://aistudio.google.com/) API key (free tier works)

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Set Up API Key
```bash
cp .env.example .env
# Edit .env and add your GEMINI_API_KEY
```

### 4. Place Dataset Files
Place the following 3 JSON files in the **project root directory** (same folder as `app.py`):
- `recipes_raw_nosource_ar.json`
- `recipes_raw_nosource_epi.json`
- `recipes_raw_nosource_fn.json`

Download from: https://eightportions.com/datasets/Recipes/

### 5. Build the Database
```bash
# Full ingestion (~125,000 recipes, takes ~1-3 minutes):
python src/ingest.py

# Quick test (100 recipes per source, ~10 seconds):
python src/ingest.py --limit 100
```

### 6. Run the Application
You can run the assistant either via the **Interactive Browser Web UI** or the **Terminal CLI**:

#### Option A: Interactive Browser Web UI (Recommended for Interviews)
```bash
python web_app.py
# Or: python app.py --web
```
Open **`http://localhost:8000`** in any browser. Features:
- 💬 **Live Chatbot Tab**: Multi-turn conversation with session state memory and one-click prompt suggestions.
- 🔍 **Task 1 Playground Tab**: Instant SQLite FTS5 search + analytical dataset statistics calculator.
- 🛒 **Task 2 Pantry Matcher Tab**: Interactive ingredient matching with explainable scoring formula breakdown.
- 🔄 **Task 3 Substitution Tab**: Local dataset recipe mining for evidence-backed ingredient substitutions.
- 📊 **Evaluation Tab**: Live benchmark scorecard from `EVAL_RESULTS.md`.

#### Option B: Terminal CLI Chatbot
```bash
python app.py
```
Supports interactive chat, `/state` to inspect memory filters, `/reset` to clear filters, and `/exit`.

### 7. Run Evaluation Suite
```bash
python eval.py
# Runs 6 multi-turn test scenarios and writes EVAL_RESULTS.md
```

## Architecture & Design Decisions

### Core Principle: Deterministic Tool-Calling Architecture

The LLM (Gemini 3.8 Flash, configurable via `GEMINI_MODEL`) acts **only** as:
1. An **intent parser** — determines which tool to call and with what parameters
2. A **multi-turn state manager** — tracks dietary restrictions, pantry, active recipe across conversation turns
3. A **response synthesizer** — formats tool results into natural language

The LLM **never** guesses counts, percentages, rankings, or recipe content. All factual operations run in Python/SQL.

### Ingredient Normalization (`src/normalize.py`)
- **Quantity stripping**: Regex removes integers, decimals, fractions (1/2, ¼, etc.) and mixed numbers (1 1/2)
- **Unit stripping**: 30+ unit tokens (cup, tbsp, oz, lb, g, clove, can, package, etc.)
- **Prep adjective stripping**: 40+ adjectives (diced, minced, fresh, ground, optional, "to taste", etc.)
- **Canonical mapping**: 80+ mappings (`tomatoes→tomato`, `garlic cloves→garlic`, `scallions→green onion`, etc.)
- **Preserved distinctions**: `milk` ≠ `coconut milk`; `peanut` ≠ `peanut butter`; `cream` ≠ `sour cream`
- **Conservative singularization**: Only strips trailing 's' for words > 4 chars (avoids `glass→glas`)

### Step Counting Rule (`count_steps` in `src/normalize.py`)
Steps = number of text fragments after splitting on (1) newlines and (2) sentence boundaries (`[.!?]\s+`) that are ≥ 4 characters and contain at least one letter. This deterministic rule is applied at ingest time and stored in SQLite.

### Pantry Matching Scoring Formula (`src/tools.py`)
```
score = (2.0 × matched_ingredients) − (1.0 × extra_required) − (0.15 × step_count)
```
Rationale:
- **+2 per match**: Strong reward for each pantry ingredient used
- **−1 per extra**: Penalty for each ingredient the user doesn't have
- **−0.15 per step**: Mild complexity penalty (prefer simpler recipes)

Hard constraints (exclusions, max steps) are enforced in SQL **before** scoring — no silently relaxed constraints.

### Ingredient Substitution Evidence (`src/tools.py`)
1. **Local dataset mining first**: Find 25 similar recipes without the target ingredient → extract frequent co-appearing ingredients as substitution candidates
2. **Evidence strength**: `strong` (≥3 supporting recipes), `indirect` (2 recipes), `weak` (<2 recipes)
3. **Web fallback**: Only triggered if evidence is `weak`. All web results tagged `[External Web Source: URL]`
4. **Disclaimer**: All substitution suggestions based on recipe text only, not medically certified

### Refusal / Uncertainty Handling
- **Missing data**: Nutrition values, calorie counts, prep times → explicitly stated as unavailable
- **No matches**: Returns empty list + closest violating alternatives (clearly flagged)
- **Weak evidence**: Explicitly states evidence strength before suggesting substitutions
- **Hallucination prevention**: System prompt forbids fabrication; tool-calling architecture prevents it structurally

### FTS5 Full-Text Search
SQLite FTS5 indexes recipe titles, normalized ingredient names (space-joined), and instructions. Used for:
- Natural language recipe search
- Finding "similar" recipes for substitution evidence mining
- Fallback: `LIKE '%query%'` if FTS5 query fails (special characters, etc.)

## Example Conversations

### Task 1: Search + Dietary Restriction
```
You: Find a penne pasta recipe
Assistant: [returns penne pasta recipes with IDs]

You: I cannot have dairy
Assistant: [re-searches with dairy exclusion, shows dairy-free penne recipes]
```

### Task 1: Statistics
```
You: How many recipes contain both garlic and onion?
Assistant: Exact count: X recipes (Y% of Z total). Normalization: "garlic cloves" → "garlic", "onions" → "onion"
```

### Task 2: Pantry Matching
```
You: I have eggs, onions, tomatoes, and rice. No peanuts, at most 6 steps.
Assistant: [ranked list with score breakdown for each recipe]

You: Exclude eggs too
Assistant: [re-runs matching with eggs excluded, updated rankings]
```

### Task 3: Substitution
```
You: Take this banana bread recipe and remove eggs
Assistant: [local recipe citations, updated ingredient list, revised instructions, predicted texture effects, disclaimer]
```
